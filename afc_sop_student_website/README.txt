African Foods Company (AFC) Simple SOP Website

This student-style website uses only HTML and CSS. It does not contain JavaScript.

Files:
- index.html: the website content
- style.css: the colours and design

How to open:
1. Extract the ZIP file.
2. Keep index.html and style.css in the same folder.
3. Double-click index.html to open it in a browser.
4. To edit it, open the folder in Visual Studio Code.
